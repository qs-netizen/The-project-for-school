# Project Jovian 🌌

A futuristic interactive website for the Project Jovian multi-moon settlement concept.

## Run locally

No Python, Node.js, npm, or API key is required.

### VS Code
1. Extract the ZIP.
2. Open the `Project_Jovian` folder in VS Code.
3. Open `index.html`.
4. For the best experience, install the VS Code extension **Live Server** and choose **Open with Live Server**.

You can also double-click `index.html` and open it directly in a browser.

## Files
- `index.html` — complete website and content
- `style.css` — futuristic responsive UI and animations
- `script.js` — animated starfield and navigation

## Concept
- Io — Energy
- Callisto — Research
- Ganymede — Industry & Resources
- Europa — Residence

This is a conceptual research project. Engineering claims should be verified against current NASA/ESA data before formal submission.
